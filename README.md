# 2GIS Design System Tokens

Source of truth дизайн-токенов веб-проектов 2GIS (dev.2gis.ru).
Первично наполняется из Figma (Tokens Studio), далее служит источником для кода (Next.js)
и для ИИ-агентов (Open Design + Codex).

## Структура

- `tokens/` — сеты токенов: один файл = один сет Tokens Studio.
  - `primitive.*` — сырые значения: палитра, типографические шкалы, метрики.
    В коде и генерациях напрямую НЕ используются.
  - `semantic.*` — ролевые токены: фоны, текст, обводки, отступы, текстовые стили.
    Единственный слой, который используют код и ИИ-агенты.
- `themes.json` — манифест тем: какие сеты составляют light и dark.
- `scripts/qa.js` — проверки целостности: валидность JSON, чистота слоёв, зеркало light/dark.
- `dist/` — артефакты сборки (не коммитятся): `tokens.css`, `tokens.ts`.
- `ai-context/` — артефакты для ИИ (не коммитятся… генерируются): `tokens-reference.md`.

## Правила слоёв (обязательны к соблюдению в каждом коммите)

1. Hex-коды существуют ТОЛЬКО в `tokens/primitive.color.json`.
2. Semantic-токены ссылаются на примитивы только через `{...}` и никогда не дублируют значения.
3. Пути `semantic.color.light` и `semantic.color.dark` зеркальны один в один.
4. Каждый semantic-токен обязан иметь `$description` по формуле «что это + где применять».
5. Новые токены рождаются в Figma (Tokens Studio) и приезжают сюда экспортом;
   правка значений напрямую в репозитории допустима только с синхронным изменением в Figma.

## Темы

| Тема | Состав сетов |
|---|---|
| light | primitive.* + semantic.space + semantic.type + semantic.color.light |
| dark  | primitive.* + semantic.space + semantic.type + semantic.color.dark |

В коде: `:root` — светлая тема, `[data-theme="dark"]` — переопределения тёмной.
Пути токенов между темами идентичны — компоненты тему не знают.

## Конвенции имён

- Файлы/сеты: `слой.роль[.тема]`, строчные, разделитель-точка.
- Пути токенов: kebab-case для слов (`text-and-icon`, `button-primary`).
- Типографика и метрики: value-based имена (`fontSize.16`, `lineHeight.24`, `space.16`, `radius.12`).
- Прозрачности: `black.alpha.12` = black.100 с прозрачностью 12%.

## Процесс обновления токенов (для людей)

1. Изменить токены в Figma-файле ДС (Tokens Studio).
2. Экспортировать сеты: для каждого изменённого сета `{}`-view → копировать →
   заменить соответствующий файл в `tokens/`.
3. Запустить `node scripts/qa.js` — все проверки должны быть OK.
4. Открыть PR: CI повторно прогонит qa и сборку.

## Сборка

```bash
npm i
npm run qa      # проверки целостности
npm run build   # dist/tokens.css, dist/tokens.ts, ai-context/tokens-reference.md
```
