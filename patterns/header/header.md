# Header 2GIS (канонический)

## Статус
**CANONICAL** — не переделывать, копировать как есть.

## Файлы реализации
- HTML: `patterns/header/header.html`
- CSS: `patterns/header/header.css`
- Логотип: `assets/logo/2gis-logo.svg`

## Структура
Две строки:
1. **header-top** (56px) — логотип, поиск, язык, кнопки "Контакты" и "Оставить заявку"
2. **header-nav** (80px) — дропдаун "Все продукты" + ссылки навигации, фон #283136, radius 16px

## Ключевые значения (из Figma)
- Контейнер: 1168px
- Скругление кнопок: **12px** (не 8px!)
- Скругление nav-панели: **16px**
- Скругление поиска: **12px**
- Font-size навигации: 16px (body-md)
- Gap в навигации: 32px
- Кнопка "Оставить заявку": фиксированная ширина 190px

## Правила
- Логотип всегда ссылка на главную
- Дропдаун "Все продукты" — единственный раскрывающийся элемент
- Цвет ссылок навигации: ink-secondary (rgba(255,255,255,0.64))
- Hover ссылок: ink (#FFFFFF)
