# Footer (футер 2ГИС)

## Когда использовать
Нижняя часть любого лендинга 2ГИС. Канонический блок — копируется дословно.

## Структура
Две горизонтальные полосы:
1. **Верхняя** (фон #283136): логотип + 4 колонки навигации + блок Telegram
2. **Нижняя** (фон #3C454B): копирайт слева, контакты справа

## Файлы реализации
- HTML: `patterns/footer/footer.html`
- CSS: `patterns/footer/footer.css`
- Логотип: inline SVG (тот же, что в хедере, размер 48×48)

## Ключевые значения
- Контейнер: 1168px, padding 0 16px
- Верхняя часть: padding 64px 0 48px
- Нижняя часть: padding 32px 0, фон #3C454B
- Заголовки колонок: 16px/24px/500, цвет #FFFFFF
- Подзаголовки: 16px/24px/500, цвет rgba(255,255,255,0.64)
- Ссылки: 14px/20px/400, цвет rgba(255,255,255,0.36), hover #FFFFFF
- Акцентная ссылка "Личный кабинет": #22AA27
- Gap между колонками: 32px
- Gap между заголовком и подзаголовком: 24px
- Gap между подзаголовками: 36px
- Gap между ссылками: 8px
- Gap между группами ссылок: 20px
- Иконка внешней ссылки ↗: 24×24, цвет rgba(255,255,255,0.64)
- Иконки контактов (телефон, email): 20×20, фон rgba(255,255,255,0.12), radius 3.33px
- Иконка Telegram: 24×24

## Правила
- Копировать разметку и стили дословно, посимвольно
- Разрешено менять: href ссылок, тексты ссылок, alt логотипа
- Запрещено: менять структуру, размеры, зазоры, радиусы, цвета
- Все стили — через var(--…) из design-rules.md
- Шрифт — только "Suisse Intl"

## Мобильная версия

### Когда использовать
На экранах шириной до 768px (планшеты и телефоны).

### Адаптации
- **Логотип**: 40×40px (вместо 48×48)
- **Колонки**: вертикальный стек (вместо 4 колонок)
- **Заголовки секций**: 16px/20px/500, с аккордеоном
- **Подзаголовки**: 14px/20px/500
- **Ссылки**: 14px/20px/400
- **Отступы**: 32px вертикально, 16px горизонтально
- **Аккордеон**: секции сворачиваются/разворачиваются по клику
- **Внешние ссылки**: без стрелок 
- **Контакты**: в одну колонку, под копирайтом

### Breakpoints
- `@media (max-width: 768px)` — основная мобильная версия
- `@media (max-width: 375px)` — очень маленькие экраны

### JavaScript
Простой скрипт для аккордеона (переключение `aria-expanded` и класса `is-open`).
