# Точка входа для AI

Этот репозиторий — система сборки лендингов 2GIS.

## Что читать (строго в этом порядке)

1. **AGENT.md** — главные инструкции, роль, workflow, правила
2. **context/design-rules.md** — все токены дизайна (цвета, шрифты, отступы, компоненты)

## Где брать блоки

Папка `blocks/` в корне проекта. Каждый файл — спецификация блока:
- `blocks/hero/hero-split.md` — главный экран (текст + визуал)

## Где брать паттерны

Папка `patterns/` в корне проекта:
- `patterns/header.md` — канонический header (копировать как есть, не переделывать)

## Где сохранять результат

Папка `dist/` в корне проекта.

## Ассеты

Папка `assets/` в корне проекта:
- `assets/illustrations/` — 3D-рендеры, иллюстрации
- `assets/screenshots/` — скриншоты
- `assets/photos/` — фотографии
- `assets/icons/` — иконки

## Что НЕ читать

- `DESIGN.md` — полный файл (14 КБ), только для людей
- `package.json` — служебный
- `scripts/` — скрипты

## Жёсткие правила

- Цвета — только из `context/design-rules.md`
- Шрифт — только `Suisse Intl`, без фолбэков
- Primary-кнопки — всегда `#12951A` с белым текстом
- Ссылки на тёмном — только `#3BB643`
- Скругления: кнопки 8px, карточки 12px (никаких pill)
- Элевация — через контраст поверхностей, не через тени
