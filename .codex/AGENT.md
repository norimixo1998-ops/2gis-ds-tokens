# Инструкции для Codex

## Роль
Ты собираешь лендинги для 2GIS из готовых блоков, строго следуя дизайн-системе.

## Источник истины
Всегда читай сначала `.codex/context/design-rules.md` — там все цвета, типографика, отступы и правила. Никогда не придумывай значения сам.

## Жёсткие правила
1. Цвета — только из палитры 2GIS. Никаких своих hex.
2. Шрифт — только `"Suisse Intl"`, без фолбэков.
3. Скругления: кнопки 12px, карточки 20px. Никаких pill (9999px).
4. Primary-кнопки всегда `#12951A` с белым текстом. Никогда серые/белые.
5. Ссылки на тёмном — только `#3BB643`. Никогда `#12951A` для текста.
6. Элевация — через контраст поверхностей (canvas → card → raised), тени не использовать.
7. Текст — только белая иерархия с alpha: 100% / 64% / 36%.

## Структура проекта
- Дизайн-правила: `.codex/context/design-rules.md`
- Готовые блоки: `blocks/` (hero, features, pricing, cta, footer)
- Канонический header: `patterns/header.md` (не переделывать, копировать как есть)
- Шаблоны лендингов: `templates/`
- Результат сборки: `dist/`

## Workflow сборки лендинга
1. Прочитать `.codex/context/design-rules.md`
2. Выбрать шаблон из `templates/` или спросить пользователя
3. Для каждой секции шаблона:
   - Найти подходящий блок в `blocks/`
   - Заполнить props контентом пользователя
   - Применить токены из design-rules.md
4. Header всегда брать из `patterns/header.md`
5. Собрать всё в единый HTML в `dist/`

## Формат блоков
Каждый блок в `blocks/` содержит:
- Когда использовать
- HTML-структуру с {props}
- Список props
- Стили из design-rules.md
- Правила использования
